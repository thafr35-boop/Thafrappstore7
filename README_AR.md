# تطبيق عبدالرحمن ظافر للهواتف الذكية (Android APK Project + QuickSell Pro)

يحتوي هذا المجلد على المشروع الكامل لتطبيق **"عبدالرحمن ظافر للهواتف الذكية"** المطابق لمواصفات **QuickSell**، مع كود أندرويد الأصلي (`MainActivity.java` و `AndroidManifest.xml`) المجهز لاستقبال الصور مباشرة من **الاستوديو (المعرض)** عبر خيار **"مشاركة" (Share)**.

## أبرز المميزات المدمجة:
1. **استقبال الصور من الاستوديو إلى التطبيق مباشرة (`ACTION_SEND` & `ACTION_SEND_MULTIPLE`)**:
   - عند فتح المعرض في هاتفك وتحديد صورة أو مجموعة صور لهواتف ذكية والضغط على **مشاركة**، سيظهر لك تطبيق **"عبدالرحمن ظافر للهواتف الذكية"**.
   - بمجرد اختياره، تنتقل الصور تلقائياً إلى قسم **استوديو المشاركة بالصور** داخل التطبيق لتحويلها إلى كتالوج أو منتجات مسعّرة بضغطة واحدة.
2. **المشاركة بالصور المختومة (Share as Images)**:
   - طباعة اسم الهاتف، السعر (تجزئة / جملة B2B / موزع VIP)، المواصفات، وشعار "عبدالرحمن ظافر للهواتف الذكية" مباشرة على صورة الهاتف ومشاركتها عبر واتساب.
3. **إدارة الطلبات، رادار العملاء المهتمين، وحماية الخصوصية**.

## طرق تثبيت واستخراج ملف الـ APK:
### الطريقة الأولى: التثبيت الفوري على الهاتف (بدون كمبيوتر)
- افتح ملف التطبيق التفاعلي `abdulrahman_dhafir_smartphones_app.html` في متصفح Chrome على هاتفك الأندرويد، ثم اختر **"إضافة إلى الشاشة الرئيسية / تثبيت التطبيق"**.

### الطريقة الثانية: استخراج ملف `app-debug.apk` عبر Android Studio أو GitHub Actions
1. **عبر Android Studio**: افتح هذا المجلد في برنامج Android Studio واضغط `Build > Build Bundle(s) / APK(s) > Build APK(s)` لتحصل على ملف `app-debug.apk` جاهزاً للتثبيت.
2. **عبر GitHub Actions سحابياً (مجاناً وبدون تثبيت برامج)**: ارفع هذا المجلد إلى مستودع GitHub خاص بك، وسيقوم ملف `.github/workflows/build-apk.yml` المرفق ببناء ملف `Abdulrahman-Dhafir-Smartphones-APK.apk` تلقائياً في تبويب `Actions`.
